# 分页迭代器

给列表端点提供统一的后向遍历。来源：0.5.0 之后第二批特性。

## 方案

- **只向后翻，只用 `after`**：`before` 是取更新记录的轮询用法，混进来会让「翻到第几页」失去意义。
- **游标字段必填**，不做端点→字段的映射表。字段因端点而异（`billId`/`ordId`/`ts`），而表里填错一个的后果是静默丢数据或重复数据——必填参数在调用点就报错。
- **终止条件两条**：空页、游标未推进。短页不终止——端点会把 `limit` 截到自己的上限，短页只说明撞到上限。
- **排除 page 型端点**（`get_announcements`、`get_tvb_link_list`），调用时给出专门报错。
- `begin`/`end` 原样透传，绝不当作游标。

## 未采用

- **端点→游标字段映射表**：能省掉一个参数，但要为约 50 个端点维护正确性，错一个就是静默的数据错误。等确有需求且能逐个核对文档时再加，且届时应保留显式覆盖。

## 未记 ADR 的原因

「游标字段必填」不满足「难回退」——之后加一张可选表是纯增量改动，不需要先推翻现在这个决定。理由写在 `okx/pagination.py` 的模块文档串与 CHANGELOG 里就够了。
