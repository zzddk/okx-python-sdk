问题
哨兵在 http.py 定义、transport.py 解释，config.py 与 WsBaseAsync 却不解释——`bool('-1')` 为真，私有会话拿哨兵登录并永久被拒，这条路径无人测。
方案
让 ADR-0014 指定的唯一映射 owner 把哨兵翻成空值；会话模块不再独立判断凭据有无。
收益
  • locality：无凭据只一处解释
  • leverage：两个 adapter 共用一份映射
  • 接口不变，实现吸收哨兵
  • 删除 test-only 盲区
补完 ADR-0014：它指定 session_config 为唯一映射 owner，却没让它解释哨兵。不冲突。

Worth exploringlocal-substitutable

Before · 13 参，5 个纯转发

↓ 原样塞给 ↓
ConnectionSupervisor（ADR-0016 的真 owner）
默认值在 connection.py 定义，却在两个构造器各声明一次 → 三个声明点

问题

  • leverage：加字段不穿两个构造器

Worth exploringin-process

Before · interface 与实际形状错位

但 6 个端点传的是 ↓

Transport.request(params: Any) ← 只有这里对
形状判别藏在 endpoints.py 的 PAYLOAD 约定里，不在 interface 里
After · 形状进 interface
request 的 interface 显式承认
dict（具名参数）｜ list（PAYLOAD 转发）

问题
`params` 标注成 Dict，但转发端点实际传 list；interface 少描述了它真实的一种形状，`test_typing.py` 只查有没有注解、不查对不对。
方案
让 interface 显式表达 dict 与 PAYLOAD list 两种形状，形状判别不再只活在测试约定里。
收益
  • locality：形状判别落在接口
  • interface 不再说谎
  • call site 与测试同一 seam
  • leverage：一处声明，24 个类受益
ADR-0011 已把 6 个转发端点记为 PAYLOAD；本卡只是让 interface 跟上它已经发现的事实，不冲突。

问题
`replayable` override 暴露在 24 个类共用的 seam 上，生产零调用、只有测试用，却能让无幂等键的 POST 变成可重放——单一 adapter 撑起一个假设 seam，interface 比 implementation 宽。
方案
把派生规则留在 `_is_replayable` 唯一 owner，去掉公开 override，让 interface 收窄。
收益
  • locality：可重放规则只一处
  • 接口收窄，删假设 seam
  • locality：绕过口子消失
  • 测试跨真实 interface
收紧的正是 ADR-0003 想守住的规则、不改规则本身；但去掉 override 是公开接口变更，需按 ADR-0004 的破坏性批次走，且要重开 ADR-0003 确认测试如何覆盖。
