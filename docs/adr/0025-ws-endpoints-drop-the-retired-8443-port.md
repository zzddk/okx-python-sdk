# WebSocket 端点改用默认 443 端口

OKX 于 2026-10-31 停止接受公网 WebSocket 的 8443 端口（Colo 为 2026-11-16）；443 一直是可用端口，`wss://` 默认即 443。我们决定：`okxsdk/consts/websocket.py` 的六个主机常量删除显式 `:8443`，只保留主机、路径与模拟盘的 `brokerId=9999`，并在 `test_network_hosts.py` 增加一条不变量——任何 WebSocket 主机常量都不得带非默认端口（`urlparse(value).port in (None, 443)`）。

这与 ADR-0022 同源：端点字符串是**外部事实**，不是包名或内部实现的一部分；ADR-0022 钉住「主机必须是 okx.com」，本条钉住「端口必须跟随 OKX 的默认值」。逐字节期望表仍然保留，但它记录的是当前事实，需要随 OKX 变更同步更新；不变量测试负责在有人把 `:8443` 加回来时变红。

## Considered Options

- **保留 `:8443`**：该端口已停止服务，连接直接失败，不可行。
- **显式改写为 `:443`**：行为等价，但官方 changelog 的迁移示例就是删除端口，且 `wss://` 默认 443，显式写属于多余；保留无端口形式也让「端口跟随默认」这一意图更清楚。
- **同步更新 `.scratch` 历史 harness**：那些文件记录的是当时的事实，按 ADR-0022 的惯例不回写。

## Consequences

- 导入六个常量的调用方拿到的是无端口 URL；通过 `url=` 显式传地址的调用方不受影响。
- EEA / US 区域域名常量本仓库从未提供，不在本次范围；若以后新增，同样不带端口。
- Colo 连接不在本仓库的端点集合内，其 2026-11-16 截止与本决策无直接关系。
